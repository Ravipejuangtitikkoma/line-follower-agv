Arsitektur Sistem & Spesifikasi AGV

Sistem Robot AGV Grid & Kendali LoRa

Dokumen Rancangan Teknis & Navigasi Otonom Berbasis Misi (Mission-Based Delivery) untuk Arena 3m × 3m Menggunakan Mikrokontroler Mappi32 (ESP32).

Maksud & Inti Keinginan Klien

Klien menginginkan sebuah sistem AGV (Automated Guided Vehicle) Mandiri seperti robot armada gudang pintar modern. Mobil robot bukan dikendalikan manual arah setirnya dengan remote, melainkan menerima tugas terstruktur jarak jauh dari Laptop via antena radio LoRa:

1. Kendali Misi dari Laptop (LoRa Gateway)

Operator cukup memilih rute tujuan dari komputer (misal: KIRIM KE A → C → PULANG). Data dipancarkan melalui radio LoRa frekuensi 922 MHz.

2. Eksekusi Mandiri & Safety Radar

Mobil menyusuri garis hitam (Line Follower PD), menghitung simpang (Node), berhenti di stasiun tujuan, dan otomatis rem darurat bila sensor HC-SR04 mendeteksi rintangan < 25 cm.

Denah Arena Grid 3m × 3m & Rute Misi Klien

Garis kuning merepresentasikan rute misi: START → N0 → N2 → [A] → N6 → N10 → [C]

Rute Misi Stasiun [A]-[E] Simpang (Node)

Urutan Tahap Gerak AGV

  • 1. Start → N0 → N2
    Maju keluar dari START, belok kiri di Node N0, menyusuri garis vertikal ke utara sampai tiba di N2.
  • 2. N2 → Stasiun [A]
    Belok kanan 90° di N2. Encoder menghitung jarak ±50 cm lalu berhenti 3 detik di Stasiun A (proses muat barang).
  • 3. Stasiun [A] → N6 → N10 → Stasiun [C]
    Lanjut maju lurus menembus persimpangan N6 dan N10. Begitu jarak encoder tercapai, berhenti 3 detik di Stasiun C (proses bongkar barang).
  • 4. Stasiun [C] → N14 (U-Turn Pulang)
    Maju ke N14 lalu lakukan putar balik poros 180°.
  • 5. Perjalanan Pulang ke START
    Menyusuri jalur balik (N14 → N10 → N6 → N2 belok kiri → N0 belok kanan → parkir di START). Kirim sinyal LoRa: MISSION COMPLETED.

Konfigurasi Pin Mappi32 Robot

Perhatian: Pin LoRa Internal (IO 14, 13, 12, 15, 0, 27) tidak boleh dipasang kabel eksternal!
Fungsi Hardware Pin Modul Pin ESP32 Mappi32
Motor Kiri (Maju / Mundur) IN1 / IN2 IO25 / IO26
Motor Kanan (Maju / Mundur) IN3 / IN4 IO16 / IO17 (Solder)
Sensor Garis 5 Channel S1 s/d S5 34, 35, 36, 39, 23
Encoder Motor Kiri Fase A / Fase B IO32 / IO33
Ultrasonik HC-SR04 TRIG / ECHO IO19 / IO18
LoRa Internal KMtek SPI & DIO0 IO 14, 13, 12, 15, 0, 27

Protokol Komunikasi LoRa

Frekuensi: 922 MHz (Standar AS923 Indonesia) | Format Teks Hemat Daya:

Perintah Dari Laptop:
CMD:GO:A,C  // Mulai misi ke A lalu ke C
CMD:STOP    // Rem darurat E-Stop
CMD:HOME    // Pulang langsung ke START
Laporan Telemetri Dari Robot:
STAT:ARRIVED:A       // Tiba di Stasiun A
STAT:ARRIVED:C       // Tiba di Stasiun C
STAT:OBSTACLE_HOLD   // Rem darurat (ada rintangan)
STAT:MISSION_COMPLETE // Parkir di START
